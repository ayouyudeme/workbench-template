# 可选：本机只读面板

> 不装也能用。这套界面只是一个「看和填」的壳：场景列表、身份卡、§0 交接、体积、体检报告，外加一个填表生成卡片的编辑器。

## 启动

1. 需要 Python 3.10+（Windows 上装了 python 就行）。
2. 双击 `start.bat`。浏览器会打开 `http://127.0.0.1:8765/`；端口被占用会自动往后顺延。
3. 关掉那个黑窗口即停止。

命令行也可以：

```bash
python 可选-界面/server.py            # 起服务并开浏览器
python 可选-界面/server.py --port 9000
python 可选-界面/server.py --build    # 只生成离线快照 快照.html
```

## 它能做什么

| 能做 | 不能做 |
|---|---|
| 看场景列表、身份卡、定位卡、§0、体积、体检 | 不改 `项目信息.md` 的正文 |
| 填表生成 `身份.md` / `定位卡.md`（左填右预览） | 不碰别的场景 |
| 新建场景（复制模板 + 登记索引） | 不删场景 |
| 改卡前自动备份到 `场景/<名>/备份/` | |

## 和 DSH 的关系

- 界面本身**不依赖 DSH**：不用 DSH 的人也能用它填卡、看体检。
- 只有「设为当前」那一步会尝试把卡片摘要写进 DSH 的项目人格文件。没有 DSH 时它会提示「没找到 DSH 项目人格目录」，**其它功能照常**。
- 用 DSH 的人可以设环境变量 `WB_PERSONA` 指向你的人格文件；不设则用默认路径 `~/.dsh/agents/projects/persona.md`。

## 权限说明

界面写文件用的是启动它的那个 python 进程的权限。用 `start.bat` 双击启动的窗口，权限跟你手动操作文件一样；某些被系统保护的位置（比如 `~/.dsh`）可能写不进去，界面会如实告诉你哪一步没成，不会假装成功。

## 安全

- 只监听 `127.0.0.1`，不对外网开放。
- 没有账号体系，只适合本机单人用；别把它挂到公网或局域网。
